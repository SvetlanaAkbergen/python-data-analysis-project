# Python Data Analysis Project

Аналитический проект на Python, выполненный в рамках финального проекта по аналитике данных.

## Project Overview

В проекте проведён анализ продаж, выявлены аномальные значения, исследованы продажи по товарам и складам, а также изучена связь динамики продаж с погодными условиями в Астане.

## Tasks Completed

- загрузка и первичная проверка данных;
- преобразование дат в формат `datetime`;
- группировка продаж по датам;
- анализ динамики продаж;
- визуализация временного ряда;
- поиск максимального выброса по количеству продаж;
- анализ продаж по складам, дням недели и месяцам;
- определение лидирующего товара;
- загрузка и обработка погодных данных RP5;
- расчёт среднесуточной температуры;
- объединение продаж и погодных данных;
- визуализация продаж и температуры;
- расчёт корреляции между температурой и продажами.

## Key Results

- Выявлен общий восходящий тренд продаж.
- Обнаружен выраженный аномальный провал продаж в апреле.
- Лидером продаж по средам за июнь–август на складе 3 стал `product_1`.
- Корреляция между температурой и продажами составила около **0.60**, что указывает на заметную положительную связь.
- При этом отдельные выбросы продаж не объясняются изменением температуры и могут быть связаны с другими бизнес-факторами.
